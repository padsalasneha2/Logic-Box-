# Pattern Generator and Number Analyzer

This Python program is a menu-driven application that generates star patterns and analyzes a range of numbers.

## Features

- Generate star patterns
- Check numbers as Even or Odd
- Calculate the sum of a range of numbers
- Menu-driven program
- Exit option

## Python Concepts Used

- if-elif-else
- for loop
- while loop
- range()
- input()
- Arithmetic operators

## Purpose

This project is created for learning and practicing Python loops, conditions, and basic programming concepts.
